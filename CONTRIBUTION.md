# Contributing Guidelines

## 1. Create an Issue

Every significant task must have a GitHub Issue.

## 2. Create a Branch

Create a branch for your task.

Example:

feature/login

## 3. Develop

Work only on the assigned task.

## 4. Commit

Use meaningful commit messages.

Examples:

feat: add login API
fix: resolve login validation
docs: update API documentation
test: add login tests

## 5. Create a Pull Request

Submit your completed work through a Pull Request.

## 6. Code Review

At least one team member must review the Pull Request.

## 7. Testing

The feature must be tested before merging.

## 8. Merge

After approval and testing, merge the Pull Request.
